// THE DETECTIVE'S METHOD

How we catch a trend

01

Select the variable

Choose from variables measured by NASA missions or produced by Earth science models — CO₂, sea level, ice mass, temperature, fire, or groundwater.

02

Fetch the data

We pull live data from NASA POWER and NOAA APIs where available. When APIs are offline, curated real-measurement archives are served instead — always clearly labelled.

03

Test for significance

The Mann-Kendall test — the non-parametric method Earth scientists use — computes S, Z, a p-value, and Sen's slope. A trend is reported significant only when p < 0.05.

04

Pin it to Earth

Every confirmed trend is anchored to the exact place where it occurs. Click anywhere on the globe to surface the regional trend at that coordinate.

// ABOUT THE PROJECT

Built for the 2026 NASA Space Apps Challenge

TerraTrend is an interactive Earth science tool that selects variables from NASA missions, visualises how they change over time, runs the Mann-Kendall statistical significance test, and pins every confirmed trend to the location on Earth where it is measured.

Live data: NASA POWER API · NOAA GML Mauna Loa. Archival data: GRACE-FO, Jason-3 / Sentinel-6, MODIS / VIIRS, GISTEMP v4.
